# Databases

Shared database-provisioning scripts for the MySQL-backed lesson days (01–05). Run the relevant
script once against your local MySQL server before starting that day.

| File | Creates | Used by |
|---|---|---|
| `world_db.sql` | `world` (`country`, `city`, `countrylanguage`) | Day 01 — being retired, see below |
| `Parch & Posey Database.sql` | `parch_and_posey` (`region`, `sales_reps`, `accounts`, `orders`, `web_events`) | Days 02–05 — being retired, see below |
| `rawaj_db.sql` | `rawaj` (14 tables — see `rawaj_erd.md`) | Planned replacement for both of the above, across Days 01–06 once those days are rebuilt around it. Generated by `_tools/generate_rawaj_db.py` — regenerate rather than hand-edit. |

All three scripts are idempotent-ish (`CREATE TABLE IF NOT EXISTS`, `INSERT IGNORE`) — safe to
re-run. `rawaj_db.sql` additionally declares real `PRIMARY KEY`/`FOREIGN KEY`/`UNIQUE` constraints,
unlike the other two.
Any new database introduced by a later lesson day goes here too, not inside that day's own folder.
