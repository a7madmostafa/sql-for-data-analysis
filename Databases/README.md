# Databases

Every database this course uses lives here — the MySQL provisioning script for the core lesson
days, and every project day's SQLite file. Run or download the relevant one before starting that
day.

| File | Creates | Used by |
|---|---|---|
| `rawaj_db.sql` | `rawaj` (MySQL) — a fictional Egyptian e-commerce marketplace (14 tables: customers, sellers, products, orders, and more) | Days 01–05 |
| `rawaj.sqlite` | A SQLite copy of `rawaj`, migrated live by `day06_python_sqlite.ipynb` — generated, not committed | Day 06 |
| `wasel.sqlite` | A fictional Egyptian ride-hailing app (cities, drivers, riders, vehicles, trips, ratings, and more), generated by `_tools/generate_wasel_db.py` | Day 07 |
| `soccer.sqlite` | European Soccer (players, teams, matches, betting odds), downloaded from Kaggle — not committed (~299 MB, over GitHub's 100 MB limit) | Day 08 |

`rawaj_db.sql` is idempotent-ish (`CREATE TABLE IF NOT EXISTS`, `INSERT IGNORE`) — safe to re-run,
and declares real `PRIMARY KEY`/`FOREIGN KEY`/`UNIQUE` constraints. `wasel.sqlite` is generated the
same reproducible way (`_tools/generate_wasel_db.py` uses a fixed random seed).

Any new database a later day introduces goes here too, not inside that day's own folder.
