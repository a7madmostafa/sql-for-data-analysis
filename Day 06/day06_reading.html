Day 06 of 9 · Project: NBA

Project: NBA

The first applied project — twenty real questions, no new SQL syntax, against a 16-table dataset that wasn't built with any of them in mind.

What you'll be able to do after this lesson

  • Read and orient yourself in an unfamiliar 16-table schema before writing a single query.
  • Answer real business questions with filtering, aggregation, and every JOIN shape from Day 03 — including the anti-join pattern — applied to data that wasn't pre-shaped for these exact questions.
  • Bucket dates with SQLite's STRFTIME() (by year, decade, month) — the SQLite counterpart to MySQL's DATE_FORMAT().
  • Sanity-check a surprising query result instead of reporting it at face value — twice, in this project, the obvious query is quietly wrong.
  • Turn a query result into a quick chart with pandas.plot(), reached through jupysql's %%sql magic from Day 05.

It's late August. Priya, an editor at a sports-media outlet, is six weeks from opening night and short a feature. She forwards you a database and one line: "Give me the draft piece we talked about — numbers, not vibes. Tell me what surprises you."

Attached is nba.sqlite — the league's full historical record, draft picks back to 1947, every game since 1946, no cleanup done. Her question list reads less like a spec sheet and more like a reporter thinking out loud, and that's the actual job here: there's no new SQL in this project, it's Days 01-04 (filtering, aggregation, every JOIN shape, the anti-join pattern) applied to a dataset nobody pre-shaped for these exact asks. Twice below, the obvious query is quietly wrong — sanity-checking a surprising number before you hand it to Priya is as much the point as writing the query in the first place.

•The dataset

Source: Basketball dataset by wyattowalsh on Kaggle — draft history, every game, play-by-play, officials, and pre-draft combine measurements, shipped as a single SQLite file across 16 tables. Section 0 of project_06.ipynb previews every one of them before Priya's questions start.

Download it before you start — not committed to this repo

nba.sqlite is ~2.3 GB — far over GitHub's 100 MB limit, and by a wide margin the largest dataset anywhere in this course. Every other project dataset is small enough to commit directly; this is the one exception.

1. Go to the dataset page and click Download (a free Kaggle account is required), or with the Kaggle CLI: kaggle datasets download -d wyattowalsh/basketball.

2. Unzip it — you only need nba.sqlite out of the download.

3. Place it directly in this folder: Day 06/nba.sqlite. project_06.ipynb connects with a relative path (sqlite:///nba.sqlite), so it has to sit next to the notebook.

Day 06/*.sqlite is git-ignored — once it's downloaded, there's nothing to commit, just re-download if you ever lose the file.

•Priya's list

She opens with the draft itself.

  1. Q1How has the number of players drafted per year changed, 1949-2020?
  2. Q2How old are drafted players on average, and has that changed by decade?
  3. Q3Which 10 teams have drafted the most players out of college/university?
  4. Q4Where do drafted players come from overall — high school, university, or another pro club?
  5. Q5When did teams first start drafting players out of college/university?

Then she pivots to the league's own history.

  1. Q6From 1949 to 2020, how did the number of teams playing and the number of games played change together?
  2. Q7How has the home-court win rate changed over time?
  3. Q8Has the overtime rate changed over time?
  4. Q9Which months carry the heaviest game load?
  5. Q10How has average attendance changed by decade?
  6. Q11What are the biggest home blowouts on record?

A couple of "did-you-know" asides for sidebars.

  1. Q12Does average wingspan differ by position?
  2. Q13Has the average height of drafted players changed over time?

The rest need more digging — franchise-level questions that only resolve once they're joined against the teams themselves.

  1. Q14Which current franchises have drafted the most players overall?
  2. Q15Which teams have won the most home games, and who currently runs their franchise?
  3. Q16Which teams currently have the most international players on their roster?
  4. Q17Which currently-active franchises are the oldest?
  5. Q18Which franchises have changed city or nickname the most?
  6. Q19Which referees have worked the most nationally-televised games?

And she wants to close on a person, not a stat.

  1. Q20How many of today's active players entered the league without ever being drafted?

•Running queries: %%sql, not a helper function

Every question in project_06.ipynb runs through jupysql's %%sql cell magic from Day 05 — the exact pattern day05_python_sqlite.ipynb already told you to expect here: a bare connection string, no SQLAlchemy needed.

project_06.ipynb
%load_ext sql %sql sqlite:///nba.sqlite --alias nba %%sql SELECT team_name, COUNT(person_id) AS players_drafted FROM draft_history WHERE organization_type LIKE '%University%' GROUP BY team_name ORDER BY players_drafted DESC LIMIT 10;
The two questions with charts capture their result

%%sql result_name << as the first line of a cell saves the result into a Python variable instead of just displaying it — then result_name.DataFrame() turns it into pandas for .plot(), same as Day 05's Section 10.

The table-preview loop uses {{ }} templating

The notebook's setup section loops over all 16 table names in plain Python, calling %sql SELECT * FROM {{table}} LIMIT 3 per iteration — jupysql substitutes the Python variable's value into the query text before running it.
