# Day 04 — Subqueries, CTEs, Views, Window Functions & Stored Procedures

Still on the **Parch & Posey** database from Days 02–03 (no new setup script here) — this is where
you start reusing query results (subqueries, CTEs, temp tables, views), then rank and total rows
without collapsing them (window functions), then save reusable logic inside the database itself
(stored procedures). The last core-SQL day before Day 05 applies all of it from Python.

## What you'll learn

- Write a scalar subquery (one value) and a row subquery (a tuple, matched with `IN`).
- Use a subquery as a derived table in `FROM`, then rewrite the same idea more readably with a CTE.
- Chain multiple CTEs together, and know when to reach for a temporary table or a view instead.
- Choose the right tool — subquery, CTE, temp table, or view — for a given reuse scenario.
- Compute a running total, rank, or row-to-row comparison with a window function, without collapsing rows the way `GROUP BY` does.
- Reset a window per group with `PARTITION BY`, and tell `RANK`/`DENSE_RANK`/`ROW_NUMBER` apart by how each handles ties.
- Look at a neighboring row with `LAG`/`LEAD`, for month-over-month style comparisons.
- Write, and `CALL`, a stored procedure with `IN` and `OUT` parameters, using `DELIMITER` correctly.
